# Configuration GitHub Pages

## Le site affiche une erreur 404

Suivez ces étapes pour réactiver GitHub Pages :

### Étapes à suivre :

1. **Allez sur votre repository GitHub** :
   - https://github.com/ismail-elaziz/myportfolio

2. **Cliquez sur "Settings"** (Paramètres) en haut à droite

3. **Dans le menu de gauche, cliquez sur "Pages"**

4. **Configurez la source** :
   - Branch : `main`
   - Folder : `/docs`
   - Cliquez sur **"Save"**

5. **Attendez 1-2 minutes** que GitHub Pages se déploie

6. **Votre site sera disponible à** :
   - https://ismail-elaziz.github.io/myportfolio/

### Vérification

Une fois configuré, vous verrez un message vert en haut de la page "Pages" :
```
Your site is live at https://ismail-elaziz.github.io/myportfolio/
```

---

**Note** : Tous les fichiers sont déjà prêts dans le dossier `/docs`. Il suffit juste de réactiver GitHub Pages dans les paramètres.
