## 🎯 Bubble Animation Breakdown:

### **Bubble Properties:**

```css
background: rgba(255, 255, 255, 0.05)
border: 1px solid rgba(255, 255, 255, 0.1)
backdrop-filter: blur(2px)
box-shadow: 0 8px 32px 0 rgba(255, 255, 255, 0.1)
border-radius: 50% (perfect circle)
```

### **Animation Phases:**

**Phase 1 (0-25%):** Fade In
- Bubble appears at bottom
- Opacity: 0 → 0.6
- Scale: 1

**Phase 2 (25-50%):** Rising
- Moving upward steadily
- Opacity: 0.6 → 0.8 (peak)
- Scale: 1 → 1.2 (expanding)
- Drifting left/right

**Phase 3 (50-75%):** Continuing
- Still rising
- Opacity: 0.8 → 0.4
- Scale: 1.2 → 0.8 (shrinking)

**Phase 4 (75-100%):** Fade Out
- Approaching top
- Opacity: 0.4 → 0
- Scale: 0.8 → 1
- Disappears above screen

Then **loops infinitely**!
