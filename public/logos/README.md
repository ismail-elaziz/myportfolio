# Company & Education Logos

Please add the following logo files to this directory:

## Work Experience Logos
- `casabaia.png` - CASA BAIA company logo
- `plutus.png` - PLUTUS company logo
- `agirh.png` - AGIRH company logo

## Education Logos
- `emsi.png` - EMSI (École Marocaine des Sciences de l'Ingénieur) logo
- `ista.png` - ISTA (Institut Spécialisé de Technologie Appliquée) logo

## Logo Requirements
- Format: PNG with transparent background (recommended)
- Size: Minimum 64x64 pixels (logos will be displayed at 32x32px)
- Square or near-square aspect ratio works best
- High resolution for crisp display on retina screens

## How to Add Logos
1. Save your logo files with the exact names listed above
2. Place them in this `public/logos/` directory
3. The website will automatically display them next to company/institution names
4. If a logo is missing, the entry will display without it (graceful fallback)

## Tips
- You can find official logos on company websites or LinkedIn pages
- Use tools like remove.bg to remove backgrounds if needed
- Optimize images with tinypng.com or similar to reduce file size
